# Proyecto Integrador 1A

## 1. Descripción del proyecto

El Proyecto Integrador 1A consiste en el desarrollo colaborativo de diferentes programas y herramientas utilizando programación, documentación y diseño web.

El repositorio reúne los trabajos realizados por los integrantes del equipo, incluyendo problemas de programación, pruebas, documentación y una página web que presenta el proyecto.

## 3. Problemas desarrollados

### Problema 1. Distancia entre dos puntos

Programa desarrollado en Java Swing que permite calcular la distancia entre dos puntos de un plano cartesiano utilizando sus coordenadas X y Y y la fórmula de distancia euclidiana.

- [Código fuente](problemas/problema-1/src/)
- [Pruebas](problemas/problema-1/pruebas/)
- [Documentación](problemas/problema-1/README.md)

### Problema 2. Dictamen fiscal y financiero

Programa que determina el impuesto aplicado a la compra de un equipo dependiendo de si el comprador es estudiante acreditado y si el equipo pertenece al catálogo educativo. Utiliza operaciones lógicas AND y XOR.

- [Código fuente](problemas/problema-2/src/)
- [Pruebas](problemas/problema-2/pruebas/)
- [Recursos](problemas/problema-2/recursos/)
- [Documentación](problemas/problema-2/README.md)
