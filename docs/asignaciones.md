# \## Forma de trabajo


# 1\. Cada tarea tendrá una rama independiente con el nombre indicado en la guía oficial.

# 2\. Cada responsable realizará los cambios correspondientes a su tarea.

# 3\. Los cambios se guardarán mediante commits.

# 4\. Cada responsable subirá su rama a GitHub.

# 5\. Se creará un Pull Request hacia la rama principal `main`.

# 6\. Otro integrante revisará el Pull Request.

# 7\. Después de aprobar los cambios, se integrarán en `main`.

# 8\. Se respetarán las dependencias establecidas antes de iniciar cada tarea.


# \## Revisión


# Cada integrante deberá participar como responsable de sus tareas y como revisor de al menos un Pull Request de otro compañero.


# El coordinador supervisará la integración de los cambios y la revisión final del proyecto.
