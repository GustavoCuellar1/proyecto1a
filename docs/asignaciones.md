
# Guía de asignaciones

## Objetivo

Organizar el trabajo del equipo para completar las 16 tareas del proyecto de manera ordenada.

## Organización

El proyecto está dividido entre cinco integrantes. Cada uno tiene responsabilidades específicas y debe entregar sus actividades mediante GitHub.

## Forma de trabajo

- Trabajar en una rama individual.
- Respetar las dependencias de cada tarea.
- Registrar los cambios mediante commits.
- Subir los cambios al repositorio remoto.
- Solicitar la revisión mediante Pull Request.

## Revisión

Cada integrante deberá entregar sus actividades para que puedan ser revisadas antes de integrarlas a la rama principal.

El coordinador será responsable de supervisar la integración y la revisión final.
