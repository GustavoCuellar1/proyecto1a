Proyecto integrador: módulos financiero-lógico y geométrico-vectorial

Primer semestre

Objetivo

Desarrollar soluciones mediante programas en Java que permitan aplicar los fundamentos de la lógica proposicional y las matemáticas para resolver dos problemas relacionados con las tecnologías de la información: determinar el porcentaje de impuesto aplicable a la adquisición de equipos informáticos y calcular la variación de posición y la distancia entre dos puntos en un plano cartesiano.

Planteamiento del problema

En el ámbito de las tecnologías de la información existen situaciones que requieren aplicar procedimientos lógicos y matemáticos para obtener resultados precisos. Este proyecto aborda dos situaciones:

Problema 1. Módulo financiero-lógico

Se necesita determinar automáticamente el impuesto aplicable a la compra de equipos informáticos, considerando si el comprador es estudiante acreditado y si el equipo pertenece al catálogo educativo. Según estas condiciones, se establece una exención del 0 %, un impuesto reducido del 8 % o un impuesto general del 16 %.

Problema 2. Módulo geométrico-vectorial

Se necesita calcular el desplazamiento entre dos puntos de un plano cartesiano. Para ello, se determinan los incrementos en los ejes X y Y y la magnitud del vector resultante mediante el teorema de Pitágoras.

Metodología

1. Análisis del problema

Se analizaron los planteamientos de los dos problemas para identificar sus objetivos, datos de entrada, operaciones y resultados esperados. En el problema financiero-lógico se identificaron las condiciones relacionadas con el estudiante y el equipo del catálogo educativo. En el problema geométrico-vectorial se determinaron las coordenadas de dos puntos para calcular sus diferencias y la distancia entre ellos.

2. Proceso de programación

Se desarrollarán dos programas utilizando el lenguaje Java. Para el primer problema se utilizarán condiciones lógicas que permitan determinar el porcentaje de impuesto correspondiente: 0 %, 8 % o 16 %, según las condiciones del comprador y del producto. Para el segundo problema se realizarán operaciones matemáticas para calcular las diferencias en X y Y, y posteriormente la distancia entre los dos puntos mediante el teorema de Pitágoras.

3. Proceso de pruebas

Se realizarán diez pruebas manuales para cada programa. Primero se calcularán los resultados esperados y después se ejecutarán los programas para comparar los resultados obtenidos. Se probarán diferentes valores de entrada, incluyendo casos habituales y situaciones especiales, con el propósito de comprobar el funcionamiento de las soluciones y detectar posibles errores.

4. Trabajo colaborativo

El equipo organizará el proyecto mediante Git y GitHub. Cada integrante trabajará en una rama asignada, realizará los cambios correspondientes y los compartirá mediante un Pull Request dirigido a la rama principal (main). Otro integrante revisará cada solicitud antes de integrarla. Este procedimiento permitirá organizar las actividades, revisar el trabajo y mantener un registro de las contribuciones de cada participante.

Análisis de resultados

Problema 1. Módulo geométrico-vectorial

Se realizaron diez casos de prueba para comprobar el cálculo de los incrementos en X y Y, así como la distancia entre dos puntos del plano cartesiano. Se utilizaron coordenadas positivas, negativas y decimales, además de puntos con desplazamientos horizontales, verticales y puntos iguales.

Los resultados obtenidos coincidieron con los resultados esperados. Se comprobó que el programa calcula correctamente los incrementos y aplica la fórmula de distancia entre dos puntos. Durante las pruebas se identificó un detalle en una etiqueta de la interfaz gráfica, que muestra un nombre incorrecto para una coordenada, pero esto no afecta los cálculos.

Problema 2. Módulo financiero-lógico

Se realizaron pruebas para comprobar las operaciones lógicas AND y XOR, así como la aplicación de los porcentajes de impuestos del 0 %, 8 % y 16 %. También se verificó el cálculo del impuesto y el total a pagar utilizando diferentes precios.

Los casos ejecutados permitieron comprobar que el programa aplica correctamente las condiciones lógicas y realiza los cálculos financieros esperados. La versión actual no incluye validación de datos, ya que esta función no forma parte de los requisitos solicitados para el programa.

Dificultades y limitaciones

Durante el desarrollo se presentaron detalles relacionados con la interfaz gráfica y la comprobación de los resultados. En el primer problema se identificó un error en el texto de una etiqueta. En el segundo problema, el programa se limita a realizar las operaciones solicitadas y no contempla la validación de entradas incorrectas.

Conclusión

Con el desarrollo de este proyecto se aplicaron conocimientos de programación en Java, operaciones matemáticas y lógica proposicional para resolver dos problemas relacionados con las tecnologías de la información. Las pruebas permitieron comprobar el funcionamiento de los cálculos geométricos y financieros. En general, los programas cumplen con las operaciones principales planteadas y permiten observar la importancia de realizar pruebas para comprobar los resultados de una solución informática.
