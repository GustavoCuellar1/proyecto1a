## 5. Reglas de colaboración



1. Cada integrante utilizará su propia cuenta de GitHub.

2. Cada tarea tendrá su propia rama, respetando el nombre oficial indicado en la guía.

3. Cada responsable realizará sus propios commits.

4. Los cambios se subirán a GitHub mediante `git push`.

5. Cada tarea se propondrá mediante un Pull Request hacia `main`.

6. Cada Pull Request tendrá un revisor diferente del responsable.

7. Se respetarán las dependencias antes de comenzar una tarea.

8. El revisor comprobará los cambios y solicitará correcciones cuando sea necesario.

9. Una tarea solamente se marcará como integrada cuando su Pull Request haya sido fusionado en `main`.

10. Los enlaces de los Pull Requests se agregarán a esta tabla cuando sean creados.
