## 4. Reglas de colaboración

1. Cada integrante utilizará su propia cuenta de GitHub.
2. Cada integrante trabajará en su propia rama.
3. Cada integrante realizará sus propios commits.
4. Los cambios se subirán mediante git push.
5. Cada integrante creará un Pull Request para integrar sus cambios.
6. Se respetarán las dependencias de las tareas.
7. El coordinador revisará la integración final.
